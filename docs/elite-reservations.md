# 尊尚預約：0.8 候選實作

這是遊戲商務資格及時刻預約，不代表真實 Uber Elite 批准、牌照或收入保證。合資格遊戲車款為 Alphard Hybrid／Vellfire Hybrid；課程十題答對八題後取得資格。新增資格由下一更起生效，當前更份使用開更時已固定的資格。

單人資格保存在本機；線上資格必須由已驗證司機帳號完成伺服器核分。線上答題紀錄和資格以新增 `0006_driver_elite.sql` 保存；不重置生涯紀錄、觀察期或 Pro 權益。錯誤答案、偽造分數、其他帳號的答題紀錄均不能授予資格。同次提交可重試，提交後不能改答案。

新增功能只在 `advancedRulesVersion:1` 的新更份／新房間啟用。舊遊戲、舊房間和不支援的客戶端不會自動獲得預約服務。部署須先套用新增 schema；停止建立新進階房間也不能把已建立的進階更份交回不懂此狀態的舊程式讀取。

## 遊戲規則

- 每個固定六小時遊戲窗口只作一次 seeded 抽選，25% 機會出現邀請；反覆 tick、載入和切換畫面不重抽。一般預約不會變成每隔幾秒的即時訂單。
- 於預約時間前兩小時邀請，前半小時截止回覆；未於上客時間後十分鐘到達視為失約。上述時間均為遊戲設定，不是真實平台門檻。
- 邀請包含真實命名地點和合法道路上的本地安全進場路段。這只是遊戲安全代理規則，不等於現實准停授權。
- 手動「保留預約」只建立未來承諾，不立即載客、計收入或自動駛往上客點。普通自動接單不會自動接受長期預約。
- 接受時核對車型、資格、人數、能源、交更時間及當前承諾。已有乘客或預接行程時不搶走現有行程；接受後的普通單也須留出返回預約上客點的時間和能源。
- 玩家手動「前往預約上客點」。提早到達會實際停止行車，等到約定時間後才開始等候／上車。乘客上車後取消，仍走既有安全落客流程。
- 一張預約最多四名乘客、兩件大行李；這是遊戲容量設定，並不推斷六名乘客加六件大行李必定適合七座車。
- 固定淨合約價為同程標準遊戲私家車淨報價 ×1.8、最低 HK$200，沒有再扣固定平台佣金；不疊加供需倍率或 Pro 優先。這不是官方 Elite 司機淨價。
- 盲單模式同樣適用：保留前只見上客地點、時間、人數和行李；目的地及載客路線上車後才顯示，車資完成後才顯示。取消沒有車資。
- 多人共用同一預約 passenger ID；伺服器只讓一位司機保留，其他邀請撤回不計拒單。命令序號重送不重複接單或計收入。

## 已驗證範圍

純引擎測試涵蓋抽選與恢復不重抽、人工承諾、普通單撞期、早到停車／準時上客、到達寬限、取消及安全落客、交更結算、盲單原始資料遮罩。SQLite 測試涵蓋核分、認證耐久、同次提交冪等、偽造／他人紀錄拒絕、永久維護 fence 和 schema 前後相容。主線接通已核實資格後，兩位司機的實際 authority 整合測試亦通過：相同預約只可一人保留、另一邀請撤回不計拒單、同序號重送不重複接受、冷恢復保留開更資格與承諾。

本文件不把模擬狀態測試當成真實完整更次、原生 UI 驗收或已部署服務；發佈及裝置證據以該版本 QA 收據為準。
